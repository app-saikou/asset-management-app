# リリースノート v1.4.2

## 日本語

**通知が毎月届くように。グラフと操作性も改善しました。**

### 改善

**資産推移グラフ**

- グラフのデフォルト表示範囲を「目標年齢まで」に変更しました。「全期間を表示」ボタンで100歳までの推移も確認できます。

**はじめての設定（オンボーディング）**

- 金額や年齢の入力をスライドするだけで選べるピッカー形式に改善しました。より直感的に設定できるようになりました。

### バグ修正

- 月次通知が最初の1回で止まってしまう問題を修正しました。毎月継続して届くようになりました。
- 資産推移グラフでマイナス値が正しく表示されない問題を修正しました。
- まれにログイン後の画面遷移が正しく行われないことがある問題を修正しました。

---

## English

**Monthly notifications now work reliably. Graph and onboarding also improved.**

### Improvements

**Asset Projection Graph**

- The default view now shows your projection up to your target age. Tap "Show full range" to see the full projection through age 100.

**Onboarding**

- Replaced number inputs with a scrollable picker for amounts and ages. Much easier to set up on first launch.

### Bug Fixes

- Fixed an issue where monthly notifications would only fire once and stop. Notifications now continue every month as expected.
- Fixed incorrect display of negative values in the asset projection graph.
- Fixed a rare issue where the app screen wouldn't transition correctly after login.
