# リリースノート v1.4.1

## 日本語

**結果画面の体験を、もっとなめらかに。**

### 改善

**結果画面のグラフ表示**

- グラフが読み込まれるまでの間、レイアウトがガラッと変わらないようスケルトン表示（仮のグレーのプレースホルダー）を追加しました。データが来たときに画面が急に切り替わる感じがなくなります。
- グラフ読み込みに関するデータ取得を効率化し、表示が速くなりました。

**「ホームに戻る」ボタン**

- 資産更新後の結果画面で、「ホームに戻る」ボタンがスクロール位置に関係なく画面下部に常に表示されるようになりました。

**資産更新フロー**

- 更新完了後から広告表示の間の待ち時間を短縮しました。

---

## English

**A smoother experience on the result screen.**

### Improvements

**Graph on Result Screen**

- Added skeleton placeholders while the graph loads — so the layout no longer jumps when data appears. No more sudden "bam" transitions.
- Optimized data fetching for the graph, making it load faster.

**"Back to Home" Button**

- The "Back to Home" button on the result screen is now fixed at the bottom of the screen, always visible regardless of scroll position.

**Asset Update Flow**

- Reduced wait time between completing an update and the ad appearing.
