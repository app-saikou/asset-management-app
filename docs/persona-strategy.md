# Tanao ペルソナ & マネタイズ戦略

## コアペルソナ

### 「Excelで老後計算しようとして挫折した30代サラリーマン」

| 項目 | 内容 |
|------|------|
| 年齢 | 27〜34歳 |
| 属性 | 共働き会社員、世帯年収700〜1200万円 |
| 投資状況 | 楽天証券/SBIでオルカン・S&P500を積み立て中。iDeCo/NISA口座は開設済み |
| 最大の不満 | 「全部合わせて65歳でいくらになるか」が見えない |
| 代替手段 | マネーフォワード（過去しか見えない）、Excel（途中で諦めた） |
| 使う場面 | 給料日後・ボーナス後・年末に「このペースで大丈夫か」を確認したい時 |

### このペルソナが「喉から手が出るほど欲しいもの」

```
「今の生活を続けると、65歳でいくらになるか」が30秒でわかること
「毎月5万円多く投資したら」「年利7%だったら」をすぐ試せること
その数字が美しいグラフで見えて、モチベーションになること
```

## 無料/有料 線引き戦略

### 現状の問題点

- 利率カスタマイズを有料にするのは逆効果
  - 利率 = 将来予測の精度 = アプリの存在意義
  - 固定利率で出した「嘘の数字」は信頼されない → アンインストール

### 推奨する線引き（最終形）

> 詳細設計・実装ロードマップは `docs/monetization-design.md` 参照

| 機能 | 無料 | Pro | 実装状況 |
|------|------|-----|---------|
| 資産登録数 | 3つまで | 無制限 | ✅ 実装済み |
| 利率カスタマイズ | ✅ 可能 | ✅ 可能 | ✅ 実装済み |
| 棚卸し（資産更新） | 月2回まで | 無制限 | ✅ 実装済み |
| 予算期間 | 1つまで | 無制限 | ✅ 実装済み |
| 広告 | あり | なし | ✅ 実装済み |
| 棚卸し履歴 | 直近3件 | 無制限 | ❌ 未実装（UI追加のみ） |
| **シナリオ比較** | ✗（1回体験可） | ✅ Pro目玉 | ❌ 未実装 |
| **取り崩しシミュレーション** | ✗ | ✅ Pro目玉 | ❌ 未実装 |
| グラフ保存/共有 | ✗ | ✅ | ❌ 未実装 |
| インフレ考慮表示 | ✗ | ✅ | ❌ 未実装 |
| ウィジェット | ✗ | ✅ | ❌ 未実装 |

### 無料で「物足りない」を作る設計思想

```
[使える]     3資産まで登録、将来予測グラフが見える
[わかる]     「もう1つ資産を追加したい」「月3回目の棚卸しをしたい」で壁に当たる
[物足りない] 資産が増えるほど、更新頻度が上がるほど、制限がジワジワ気になる
[損しない]   無料でも「65歳でいくらになるか」は正確に見える
```

## 有料プラン（Pro ¥980/月）の訴求軸

### 「シナリオ比較」が最大の目玉

> 毎月の投資額を変えたら将来がどう変わるか、2プランを並べて比較できる

このペルソナが一番やりたいことがProに入る設計。

### 「取り返せない感」を作る体験

1. 無料期間中にシナリオ比較を体験させる
2. 試用終了後、シナリオBのグラフが消える
3. 「あの数字をもう一度見たい」でPro継続

## UI改善の優先順位（ペルソナ視点）

### 🔴 最優先: ホーム画面に「将来予測サマリー」を常時表示

```
[現在] 総資産 ¥5,234,000
       現金 40% / 株式 60%

[理想] 総資産 ¥5,234,000
       65歳（32年後）→ 予測 ¥47,200,000
       目標まで ¥2,800,000 不足
       ─────────────────────
       毎月 +¥10,000 で目標達成できます  ← Proで試算
```

毎日開く理由ができる。数字が動くたびに「正しい方向に向かっている」安心感。

### 🔴 最優先: 予算・目標をホームから直接編集

タブ遷移なしで「毎月の積立額」「目標年齢」を即変更 → 予測がリアルタイム更新。

### 🟡 高優先: App Storeのキーワード最適化

「老後 シミュレーション」「FIRE 計算」「iDeCo 将来」「資産形成 アプリ」でペルソナが検索する言葉と一致させる。

## まとめ

ペルソナに刺さる一言コピー案：

> **「Excelで挫折した将来計算を、30秒で。」**

このペルソナは「正確な数字で老後の不安を解消したい」。
アプリの核心価値は **「将来が見える安心感」** であり、それをホーム画面に常時表示することが最大の改善点。
