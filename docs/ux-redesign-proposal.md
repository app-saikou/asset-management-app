# Tanao UI/UX 改善提案 — ペルソナ導線の完全設計

> 最終更新: 2026-04-06  
> 対象ペルソナ: 「Excelで老後計算しようとして挫折した27〜34歳の共働きサラリーマン」

---

## 結論から言う

**現状のTanaoはツールとして正しいが、体験として弱い。**

ペルソナが欲しいのは「数字が出る計算機」ではなく、  
**「65歳の自分の財布が見える窓」** だ。

今のアプリは窓がある。でも窓が小さく、汚れていて、カーテンがかかっている。

---

## 現状のUX課題マップ

### ペルソナの1回の使用シナリオ

```
給料日後、夜10時。子どもを寝かしつけた後。
「今月もちゃんと積み立てた。で、今何円になってるんだっけ。」
                          ↓
アプリを開く（3秒）
                          ↓
[現状] 総資産と内訳が見える → 「で？」（感情が動かない）
[理想] 「65歳に4,700万円」が目に飛び込む → 「おっ、増えてる」（継続モチベーション）
                          ↓
「先月より増えた。よかった。」で閉じる（30秒）
```

このシナリオを妨げている箇所を6軸で評価する。

---

## 6軸レビュー

### 1. First Impression ★★★☆☆

**問題:** ホーム画面の視覚的ヒエラルキーが間違っている。

```
現状のレイアウト:
┌──────────────────────┐
│  総資産 ¥5,234,000    │  ← 現在（過去の積み重ね）
│  現金 40% / 株式 60%  │
├──────────────────────┤
│  65歳時の予測資産      │  ← 未来（アプリの存在意義）
│  ¥47,200,000         │
├──────────────────────┤
│  [現金] [株式] タブ   │  ← 明細
└──────────────────────┘
```

**ペルソナが最初に見たいのは「未来」のはず。** なぜ「現在」が主役なのか。

**改善案: 未来を主役にしたレイアウト**

```
理想のレイアウト:
┌──────────────────────────────┐
│  65歳（32年後）の予測資産      │  ← ヒーロー
│  ¥4,720万                    │
│  今より +¥4,197万 ↑           │
│  [毎月の積立を変えてみる →]    │  ← CTA (Proへの導線)
├──────────────────────────────┤
│  現在の総資産 ¥523万           │  ← サブ情報
│  現金 ¥210万 / 株式 ¥313万    │
├──────────────────────────────┤
│  [資産を更新する]             │  ← アクション
└──────────────────────────────┘
```

---

### 2. Interaction Design ★★★☆☆

**問題1: 棚卸しがウィザード型で重い**

現状の「資産を更新」フロー:
```
ホーム → 別画面遷移 → ステップ1（現金） → ステップ2（株式） → 完了
```
3〜5ステップ、画面遷移2回以上。「給料日後の3分」に対して重すぎる。

**改善案: 各資産カードにインライン編集**

```
┌─────────────────────────────┐
│ 楽天証券（オルカン）         │
│ ¥2,130,000                  │
│ 前回から +¥34,000 ↑          │
│ [− ]  ¥2,130,000  [＋]  [✓] │  ← その場で編集
└─────────────────────────────┘
```

`✓` を押すと即保存・予測更新。画面遷移ゼロ。

**問題2: 予測カードがタップできない（またはタップしても何も起きない）**

`FutureProjectionCard` は `onPress` を受け取るが、ホームでは渡されていないケースがある。  
「65歳の予測資産」をタップしたら何が起きるべきか設計されていない。

**改善案:** タップで棚卸しグラフ（内訳・推移）にナビゲート。

**問題3: 予測のインタラクティブ性がゼロ**

「毎月の積立を5万円増やしたら？」をホームから試せない。  
これはペルソナが最も欲しい機能（= Pro最大の訴求点）なのに、アプリから完全に見えない。

---

### 3. Emotional Design ★★☆☆☆

**問題: 数字が増えても感情が動かない**

現在のフロー:
```
棚卸し完了 → 履歴詳細画面 → 数字が表示される
```

ペルソナが「よし！」と感じる瞬間がない。  
マネーフォワードを開いて「残高が増えてる、まあそうか」と閉じる感覚と同じ。

**改善案: 棚卸し完了時の「勝利モーメント」**

```
棚卸し完了
  ↓
「今月も更新しました！」画面（fullscreen）
  ┌──────────────────────┐
  │ 🎉 今月の棚卸し完了！  │
  │                        │
  │ 先月比  +¥34,000 ↑     │
  │ 65歳予測 ¥4,720万      │
  │ 目標まで あと¥280万    │
  │                        │
  │ [シェアする] [閉じる]   │
  └──────────────────────┘
```

Haptics（成功バイブ）+ 数値カウントアップアニメーション。  
「継続している自分の努力が可視化される」体験。

---

### 4. Information Architecture ★★☆☆☆

**問題: 「予算」が深すぎる場所に埋まっている**

現状の情報構造:
```
ホーム（資産一覧）
プロフィール → 予算設定 → 予算期間編集 → 毎月の積立額
```

毎月の積立額はアプリの計算に直結する最重要設定なのに、4タップ先にある。

**改善案: ホームから「積立設定」への1タップ導線**

```
ホーム → 予測カードをタップ → [今月の積立: ¥30,000 ✏️] が編集できる
```

または FutureProjectionCard 内に「積立額を変える →」リンクを配置。

**問題: タブ構成がアプリの目的と一致していない**

現状のタブ:
```
[ホーム] [履歴] [プロフィール]
```

ペルソナの主要ユースケース:
1. 「今いくらか確認する」→ ホーム ✅
2. 「予測グラフを見る」→ ホーム（FutureProjectionCard）✅ でも入口が小さい
3. 「積立額を変えてシミュレーション」→ **どこにもない** ❌
4. 「過去の推移を見る」→ 履歴 ✅

「シミュレーション」がタブに存在しないのは致命的な欠落。

---

### 5. Delight & Engagement ★★☆☆☆

**問題: 毎日開く理由が弱い**

月1回の棚卸し以外に、アプリを開くモチベーションが設計されていない。

**改善案一覧:**

| 機能 | 効果 | 工数 |
|------|------|------|
| 棚卸し完了「連続記録」バッジ | 継続モチベーション | 小 |
| 「今月の予測が先月比+◯万円」ウィジェット | ホーム画面からの接触頻度↑ | 中 |
| 「65歳まで◯日」カウントダウン | 緊迫感・毎日変わる数字 | 小 |
| 「目標達成まで◯ヶ月」プログレスバー | 進捗の可視化 | 小 |
| グラフのSNSシェア | 口コミ獲得 + 自己投資の宣言 | 中 |

---

### 6. Accessibility ★★★☆☆

- 現金/株式の識別が色のみ（色覚多様性対応未）→ 形状を追加すべき
- タップターゲットが小さい箇所がある（万円トグルボタンなど）
- `accessibilityLabel` が未設定

## 新画面・新機能の提案

### 提案1（最優先）: シミュレーションタブ

**なぜ:** ペルソナが最も欲しいのに、今のアプリに存在しない。

**画面設計:**

```
┌─────────────────────────────────┐
│  シミュレーション                │
├─────────────────────────────────┤
│  現在の設定                     │
│  毎月の積立: ¥30,000             │
│  利率: 平均 5.8%                 │
│  目標年齢: 65歳                  │
│                                  │
│  予測: ¥4,720万                  │
│  ─────────────────────────────  │
│  「もし〜だったら」             │
│                                  │
│  毎月 +¥10,000 増やしたら?      │
│  [−−] ¥40,000 [＋＋]           │
│  → ¥5,180万（+460万）↑         │
│                                  │
│  目標年齢を60歳にしたら?        │
│  [−] 60歳 [＋]                  │
│  → ¥3,290万（−1,430万）↓       │
│                                  │
│  [Pro] 2プランを並べて比較する  │
└─────────────────────────────────┘
```

**フリーで「気づき」を与え、Proで「比較」を解放する設計。**

実装方針:
- `useHomeProjection` の計算をパラメータ化（積立額・利率・目標年齢を可変に）
- オンデマンドで再計算（DBへの保存なし）
- Pro機能: 2プランのグラフを並べて表示

---

### 提案2（高優先）: ホームのFutureProjectionCardをインタラクティブ化

**なぜ:** 現状はただの「表示」。ペルソナのメンタルモデルは「触って変えられる」。

**改善後の FutureProjectionCard:**

```
┌────────────────────────────────┐
│  65歳（32年後）の予測資産 →    │
│  ¥4,720万                      │
│  今より +¥4,197万 ↑            │
│  ──────────────────────────── │
│  毎月の積立: ¥30,000  [変更]   │  ← タップで直接編集できる
│  目標まで あと¥280万           │
└────────────────────────────────┘
```

「変更」タップ → ボトムシートで金額入力 → 予測がアニメーション付きで更新。

---

### 提案3（高優先）: 棚卸し「クイックモード」

**なぜ:** 現状のウィザードは「给料日後の3分」に対して重すぎる。

**設計:**

```
資産カード（ホーム）
┌───────────────────────────────┐
│ 楽天証券（オルカン） 株式     │
│ ¥2,130,000                    │
│ [資産を更新] ← ここにボタン   │
└───────────────────────────────┘

「資産を更新」タップ → ボトムシート
┌───────────────────────────────┐
│  楽天証券（オルカン）を更新   │
│                                │
│  現在: ¥2,130,000              │
│  新しい金額: [¥___________]   │
│                                │
│  [キャンセル]    [更新する]    │
└───────────────────────────────┘
```

全資産一括でなく個別更新を可能にする。  
ただし既存のウィザード（`inventory-step`）も残す（全資産一括更新ニーズもある）。

### 提案4（中優先）: 取り崩しシミュレーション画面

**なぜ:** 「数億円」表示の現実味のなさを解消し、「老後の不安」という感情的動機を刺激する。

**画面設計:**

│  老後シミュレーション          │
│                                 │
│  積立フェーズ（〜65歳）        │
│  予測資産: ¥4,720万            │
│                                 │
│  取り崩しフェーズ（65歳〜）    │
│  毎月の生活費: ¥20万 [変更]   │
│                                 │
│  ────────────────             │
│  ⚠️ 資産が尽きるのは... 83歳  │
│  100歳まで生きると ¥3,720万 不足│
│                                 │

**「83歳で尽きる」という数字が、ペルソナを今すぐ行動させる。**  
これがアプリで最も感情を動かすコンテンツになれる。

## タブ構成の再設計案

### 現状
```
[資産] [履歴] [プロフィール]
```

### 提案
```
[ホーム] [シミュレーション] [履歴] [設定]
```

| タブ | 主なコンテンツ | ペルソナの使用頻度 |
|------|--------------|----------------|
| ホーム | 総資産・予測・クイック更新 | 週1〜月2回 |
| シミュレーション | 積立変更試算・シナリオ比較 | 月1〜2回 |
| 履歴 | 過去の棚卸し推移・グラフ | 月1回 |
| 設定 | プロフィール・通知・Pro | 初回のみ |

## 実装優先順位

### Phase 1: 感情が動く体験（2〜3週間）

1. **棚卸し完了「勝利画面」** — 工数小、効果大。継続率に直結
2. **ホームのFutureProjectionCardから積立設定への1タップ導線** — 既存コンポーネントの改修のみ
3. **総資産カードのカウントアップアニメーション** — 工数小、ファーストインプレッション改善

### Phase 2: コアバリューの解放（1〜2ヶ月）

4. **シミュレーションタブ** — ペルソナが最も欲しい機能。Proへの最大の動機
5. **棚卸しクイックモード** — 離脱率改善。重いウィザードが障壁になっている可能性大
6. **取り崩しシミュレーション** — 感情的インパクト最大。差別化コンテンツ

### Phase 3: 精度と継続性（3ヶ月以降）

7. **インフレ考慮オプション**
8. **連続棚卸しバッジ・ストリーク**
9. **グラフSNSシェア機能**

## まとめ

**今のTanaoに欠けているのは「感情の設計」だ。**

数字は正しい。計算も正しい。  
でも「正しい数字を見せる」だけでは、ペルソナの不安は解消されない。

必要なのは:
1. **「65歳の自分」が主役のホーム画面**（情報ヒエラルキーの逆転）
2. **「もし増やしたら」をその場で試せるシミュレーション**（コアバリューの解放）
3. **「継続している自分を褒める」棚卸し完了体験**（習慣化のトリガー）

この3つが揃って初めて、Tanaoは「使うたびに少し安心できるアプリ」になる。
