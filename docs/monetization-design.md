> 最終更新: 2026-04-07

## 設計の原則

**無料: 「65歳でいくらになるか」が正確に見える**  
**Pro: 「どうすればもっと増やせるか」が試せる**

この2行で線引きの全体像が決まる。  
無料は「現実を知る」、Proは「未来を変える」。

## Pro機能の優先順位と設計詳細

### 🥇 シナリオ比較（最優先・Pro目玉）

**なぜProの核心か:**  
ペルソナが一番やりたいのに、今のアプリで一切できない。  
「毎月5万円増やしたら老後どう変わるか」はExcelを開く理由そのもの。  
これをProに入れることで「これのためにProを続ける」が成立する。

**体験設計:**
```
シナリオA（現状）     シナリオB（仮定）
毎月 ¥30,000         毎月 ¥50,000
65歳 → ¥4,720万     65歳 → ¥6,180万
                              +¥1,460万の差
```

**「取り返せない感」を作る仕掛け:**
1. 無料ユーザーにも「シナリオBを試す」ボタンを表示（1回だけ無料体験）
2. 試用後にグラフが薄くなる（ロック演出）
3. 「あの数字をもう一度見たい」で課金動機が生まれる

**実装方針:**
- `MonthlyProjectionEngine` はパラメータを変えるだけで再計算可能（DB保存なし）
- 計算はオンデマンド、結果はメモリ内のみ
- グラフは2本の線を並列表示（`react-native-gifted-charts` のマルチライン）

---

### 🥈 取り崩しシミュレーション（Pro目玉 第2弾）

**なぜ強いか:**  
「増やす話」はモチベーションだが、「尽きる話」は危機感。  
危機感は即行動につながる。これが最も感情を動かすコンテンツ。

**体験設計:**
```
65歳時点の予測資産: ¥4,720万
毎月の生活費: ¥20万（編集可）

⚠️ 資産が尽きるのは... 83歳
   100歳まで生きると ¥3,720万 不足

毎月の積立を増やすと...
  +¥3万/月 → 89歳まで持ちます
  +¥5万/月 → 95歳まで持ちます（✅ Pro比較で見える）
```

**ペルソナへの刺さり方:**
「83歳で尽きる」という数字が目に入った瞬間、  
「今すぐ積立額を上げよう」という行動動機になる。  
この感情的インパクトはTanaoの最大の差別化になれる。

**実装方針:**
- 取り崩しフェーズ: 月次で `balance = balance × (1 + rate/12) - withdrawal` を繰り返す
- `user_profiles` に `monthly_withdrawal` カラム追加（または画面内の一時state）
- 結果はDB保存しない（表示専用）

---

### 🥉 棚卸し履歴 無制限

**なぜProか:**  
「去年の今頃いくらだったか」は、3件を超えてから初めて意味を持つ。  
無料の3件制限は「使い込んだユーザー」だけに当たる、理想的な制限。

**実装:** 現状の `asset_history` テーブルは無制限に保存済み。  
UI側でProチェックを追加するだけ（工数小）。

---

### グラフ保存・シェア

**なぜProか:**  
「65歳で◯円！」のシェアはバイラル拡散ツールでもある。  
Pro限定にすることで「シェアしたければPro」の動機が生まれる。  
ただしシェア画像にTanaoのロゴを入れることで無料広告にもなる。

**実装方針:**
- `react-native-view-shot` でグラフをキャプチャ
- `Share.share()` でネイティブシェアシート
- シェア画像に「Tanao で作成」透かしを入れる

---

### インフレ考慮表示

**なぜProか:**  
「今日の価値に換算すると◯円」は「数億円の現実味のなさ」を解消する高度機能。  
基本の「名目額」は無料、「実質額（インフレ調整）」はProで見せる。

**体験設計:**
```
65歳予測
名目: ¥4,720万（無料で見える）
実質（今の価値換算・2%インフレ）: ¥2,940万 ← Pro
```

「実は実質3,000万か...もっと増やさないと」という危機感への変換。

---

### ウィジェット（iOS/Android）

**なぜProか:**  
ホーム画面ウィジェットは「毎日アプリを開かなくても老後が見える」体験。  
アプリの存在感が格段に上がる。これを無料にする理由はない。

**実装方針:**
- iOS: `react-native-widget-kit` または Expo Widget extension
- 表示内容: 総資産・65歳予測・前回比
- 更新頻度: 棚卸し後のみ（バッテリー節約）

## 無料/有料の「壁の当たり方」設計

ペルソナが無料で使い込むにつれて、以下の順番で壁に当たる設計になっている。

```
1ヶ月目:  資産3つ登録 → 棚卸し2回 → 「順調」
          ↓
2〜3ヶ月目: iDeCoも追加したい（4つ目の壁）
           棚卸し3回目したい（月2回の壁）
           「来月転職するから予算変えたい」（期間1つの壁）
          ↓
半年後:   過去の推移を見たい（履歴3件の壁）
          「積立増やしたら将来どう変わる?」（シナリオ比較の壁）
          ↓
ここで課金: 月¥980なら... → 升
```

**どの壁も「使い込んだ結果として自然に当たる」設計が重要。**  
初日に壁に当たるとアンインストールになる。

## 価格設計

| プラン | 価格 | 対象 |
|--------|------|------|
| 無料 | ¥0 | お試し・ライトユーザー |
| Pro 月払い | ¥980/月 | とりあえず試したい |
| Pro 年払い | ¥7,800/年（¥650/月相当・34%OFF） | 継続使用者 |

**¥980/月の根拠:**
- マネーフォワードME Premium: ¥500/月（機能が違う）
- 家計簿アプリ平均: ¥400〜800/月
- Tanaoの差別化（将来予測・シナリオ比較）: +¥200〜400のプレミアム
- ペルソナの「コーヒー1杯分」感: ✅（スタバ1杯 = ¥600〜700）

**年払い推奨:** 年払いは解約率が月払いの1/3になる傾向。  
初回月払いで価値確認 → 年払いに誘導するフローが理想。

         ↓

7. **ウィジェット** — 毎日の接触頻度向上（2〜3週間）
8. **シナリオ比較（Pro完全版）** — 2プラン並列グラフ（1週間）

## まとめ: Pro機能の3つの柱

```
柱1「変えられる」: シナリオ比較
  → 「もし積立を増やしたら」をその場で試せる
  → ペルソナが最も欲しい機能。これがProの最大訴求点

柱2「怖さを知る」: 取り崩しシミュレーション
  → 「83歳で資産が尽きる」という事実
  → 感情的インパクト最大。即行動につながる

柱3「続けられる」: 無制限化 + ウィジェット
  → 使い込むほど快適になる
  → 解約動機を減らす
```

この3柱が揃って初めて、¥980/月の「払わないともったいない感」が成立する。
